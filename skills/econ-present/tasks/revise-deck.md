# Revise an Existing Deck

Use this when the user asks to revise or "recheck" a deck, or wants it for a different length or audience. Everything in [SKILL.md](../SKILL.md) still applies.

A deck for a different length or audience is a new deck: plan it again from [Plan the story first](../SKILL.md#plan-the-story-first) and reuse slides where they fit. Do not grow or cut an existing deck slide by slide to reach a new length.

When the user asks to revise or "recheck" a deck of the same length:

1. Keep a copy of the old `.tex` before editing, and keep its filename for the new one.
2. Re-verify against the current source first (version and date, as in [Settle the source](../SKILL.md#settle-the-source-before-building)). A deck built from an older version needs its numbers, equation numbers and page references reissued, not patched one by one.
3. A missed item that carries the argument goes into the main sequence at the point where the story needs it; anything else goes to Appendix.
4. In the handover, list what changed and why (for example a table of old versus new numbers), so the user can see what to re-check.
