## How to teach with this map

- Explain **why each task matters economically**, not just which algorithm to run.
- Where assignments revisit one economic model with different solvers, state what remains fixed and what changes (e.g., state approximation, policy representation, accuracy metric).
- Distinguish homework instructions from exact lecture notation; note explicit mappings when symbols differ.
- If course rules reserve work for the student, teach concepts and offer appropriate checks rather than silently performing prohibited deliverables.
- On targeted questions, **reopen the source Homework and Slides** to verify part numbers, assumptions, and local symbols.
