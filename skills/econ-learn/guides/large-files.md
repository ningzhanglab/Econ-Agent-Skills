# Large Files and Long Courses

No context window holds a semester. Read in passes and report coverage honestly.

1. **Discover:** list accessible files, the syllabus, headings and obvious missing assets; produce a provisional map quickly.
2. **Index:** walk each relevant lecture in bounded page ranges, keeping headings, exact page or slide locators, formula anchors and local notation. Record partial coverage. A large course may take several sessions; never promise to finish after the conversation ends.
3. **Read deeply** only the lecture and pages the current question needs, with their neighboring assumptions.

When a file is too large to parse whole, split it at chapters or pages with stable locators, never at arbitrary points that drop an assumption.

Keep the working set small: the target pages, the definitions they use and one prerequisite. Exact formulas and figures come from the original, never from a summary. Text extraction can corrupt primes, fractions, indices and Greek letters, so check equations against the rendered page or the LaTeX. Resolve a macro alias before stating its symbol.

Uploaded, text extracted, pages viewed, figures seen and material understood are different levels: say which one each claim rests on.
