# 2026-11-15 — Slides: short one-line titles

- **Date:** 2026-11-15
- **Component:** `econ-teaching` (slides reference)
- **Change type:** Changed
- **Status:** Implemented
- **Related commit / PR:** See Git history for this change

## Motivation

A Beamer deck for a paper followed the "assertion titles" rule: every title was a full sentence stating the slide's point. About 20 of 53 titles wrapped to two lines, crowded the slide, and the user judged them too long. A fixed word limit (first proposed as 3-7 words) was also judged too short for long sections, so the limit is stated as "fits on one line".

## Changes made

- `references/slides.md`, "Plan the story first", item 3: now "Short titles": one line (about 60 characters), names the content with the key term, claim and number in a bold first line or first bullet, sentence titles allowed for preview, main-result and takeaway slides if they fit one line, shorten if wrapped.
- `CHANGELOG.md`: entry added.

## Files affected

- `skills/econ-teaching/references/slides.md`: rule text.
- `CHANGELOG.md`, this log.

## Behavior and compatibility

Decks generated by the Skill get shorter titles. Nothing else in the slides reference changes (bullet and equation limits, figures, handover). Existing decks are unaffected.

## Known limitations and risks

"About 60 characters" is a judgment; Beamer title width depends on font size and aspect ratio. The deck in question also exceeded the default length (48 main slides) and bullet limits; this change does not address that.
