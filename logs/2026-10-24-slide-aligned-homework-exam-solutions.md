# 2026-10-24 — Slide-aligned Homework solving and exam preparation

## Why this change

The user explicitly requested a **general Professor Skill rule**, not a STAT 516-only preference: when solving Homework or preparing for exams, retain the professor's notation, use the same or similar reasoning as the Slides, and show the detailed steps necessary to follow the answer.

## What changed

- **Core SKILL.md:** elevated source-aligned Homework/exam solving to a teaching priority and adaptive mode. The general rule requires matching notation, assumptions, solution path and essential intermediate steps.
- **references/visuals-and-homework.md:** documented a practical source-matching process: read actual problem and nearest worked Slide, map notation differences, show setup/substitutions/pivotal algebra/answer, check the conclusion and label independently derived extensions.
- **references/teaching-design.md:** differentiated Homework solving from exam/past-paper preparation without turning either into a rigid response template.
- **README.md and DESIGN_V1.md:** updated the public behavioral guarantees.
- **CHANGELOG.md and logs/README.md:** linked this dated development record.

## Scope, constraints and behavior

This applies across Macro, Micro, Econometrics, Time Series and future courses using the Professor Skill. The nearest similar Slide is a **method reference**, not proof the particular homework problem appeared there. Never silently change symbols or claim a method is the instructor's if it is not supported by inspected materials.

The detail standard is **necessary steps rather than maximal length**. Short answers remain short when justified. Homework and exam solutions still respect the actual course's collaboration, AI-use and independent-work requirements; the Skill must not misrepresent Agent work as student work.

No course-specific private source files or student solutions were added to the public repo. No course PDF, cloud artifact or live homework benchmark was requested or produced.

## Verification

Focused editorial/readback validation of the edited paths and cross-references, with existing repository CI as the structural regression check; no new heavy benchmarking or PDF generation for this instructions-only change.

## Compatibility and future work

Preserves the v1 single Professor Skill architecture, specialist references, opt-in Learning Logs and private cloud output conventions. Reevaluate only after actual classroom use exposes a specific failure.
