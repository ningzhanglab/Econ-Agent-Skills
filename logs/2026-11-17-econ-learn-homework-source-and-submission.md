## Motivation

A real time-series Homework (an intervention model with a unit-root noise term, with the student's SAS output supplied) was solved with `econ-learn`. The user gave only the assignment file and the software output. Observed failures:

1. The agent solved from the assignment alone. The course folder beside the assignment held the lecture's worked example of the same data, which chose a different intervention form (a gradual response, chosen by lowest AIC with significant coefficients) from the one the agent picked (an immediate step, chosen by SBC and parsimony). Step 1 of the Homework page already said to find the source match, but did not say where to look when only an assignment is given, or that a "choose a model" question should use the course's own criteria.
2. The agent never opened the Time Series guide. Step 4 said to check the field's traps "where appropriate", and the routing table opened a field guide only "where a field's known traps or checks matter", so skipping it was easy. The guide would have flagged reading the SAS program before its output and the weak power of the unit-root test.
3. The agent guessed the submission filename and added an appendix the assignment did not ask for, instead of reading the assignment's submission instructions (format, filename pattern, "attach the computer output").
4. A second agent's version of the same homework carried process notes in the submitted file ("checked using uploaded SAS output", "not from the earlier Python fit"). It is not known whether that agent used this skill; the guarantee to say what was read can push toward such lines.

The user reviewed the list of proposed fixes and asked for all five.

## Changes made

- `tasks/homework-exam.md`, step 1: when only the assignment is given, look in its folder and the course folder above it for lecture notes, handouts and worked examples before solving; say so if none is found; for a question that asks for a choice, use the course's own criteria.
- `tasks/homework-exam.md`, step 4: before finishing a problem in macroeconomics, microeconomics, econometrics or time series, open that field's guide and check against its traps (was "where appropriate").
- `tasks/homework-exam.md`, Defaults: **Submission rules** (the assignment's instructions decide format, filename and attachments; add no section it does not ask for) and **What goes in the file** (the solution with its own caveats, plus any required AI-use disclosure; notes on which files were read or could not be opened go in chat).
- `SKILL.md` routing table: the field-guide row now says a Homework solution in that field opens the guide always.
- `guides/time-series.md`, common traps: a level shift biases the ADF test toward not rejecting a unit root; AIC and SBC compare only models fitted to the same observations, so check the number of residuals.

## Behavior and compatibility

A Homework request with only an assignment file now searches the nearby course folder first, and every Homework problem in one of the four fields reads its guide, which adds one guide (about 600–900 words) to those requests. Submitted files follow the assignment's own format and naming rules and contain no process notes. The `.tex` + `.pdf` default and the `Agent Outputs/` destination still apply when the assignment and the user say nothing else. No interface, script or installation change.

### Comparison run

Each run was a fresh agent with no memory of the motivating session, given the student's original one-line request, the assignment and the SAS output, and told not to open earlier solution attempts. One run per arm, same model; outputs were checked by reading the TeX, not only the agents' reports.

| Check | New version | Previous version | No skill |
| --- | --- | --- | --- |
| Looked for course material | Yes: worked example, intervention chapter and response handout read | Yes: worked example read; chapter and handout attempted but unreadable with its tools | No |
| Opened the Time Series guide | Yes | No | n/a |
| Question 1 model matches the course's choice | Yes, using the course's comparison criteria | Yes, citing the course's choice | Yes, from AIC and nesting alone |
| Filename follows the assignment | Yes | Yes | No (generic name) |
| Computer output attached and indexed | Yes (indexed appendix; transcribed numbers match the SAS output) | Partly (three SAS plots) | Partly (plots appendix) |
| Process notes in the submission | None | None | None |
| Caveats in the submission (SBC disagrees; 274 vs 275 residuals; level shift and ADF) | SBC only; the residual-count caveat was put in chat instead | All three | SBC and level shift |
| Question 2 values correct | Yes | Yes | Yes |

Findings:

- The previous version already found the course material when followed; the motivating failure was mainly one of execution. The new wording made the search more thorough (the intervention chapter and the course's comparison criteria were used).
- **Regression:** the new "What goes in the file" Default led the agent to move a substantive statistical caveat (information criteria on different residual counts) from the submission to chat. The Default was meant only for provenance (which files were read, what the tools could not open), not for caveats about the answer.
- **Correction after the run:** the Default now reads "the solution, with its own caveats (a criterion that disagrees, a test's weakness) … Notes on the work itself (which files were read, what a tool could not open) are reported in chat". The narrowed wording was not rerun.
- No skill reached the same model from the output alone, but did not use the course and did not follow the filename rule.

## Known limitations and risks

- Most of the motivating failures came from not following rules the skill already had; a firmer wording may still be skipped.
- Searching "the course folder above" depends on the host giving file access; in a cloud workspace it means the verified course folder.
- Making the field guide mandatory for Homework adds reading to short problems where it may not change the answer.
