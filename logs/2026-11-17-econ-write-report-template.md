# 2026-11-17 — econ-write report template

- **Date:** 2026-11-17

- **Status:** Implemented
- **Related commit / PR:** See Git history for this change

## Motivation

The user supplied a simple LaTeX template for homework and reports and asked for it to be added to the repository under a general name, for homework, reports and short writing.

## Changes made

- Added `skills/econ-write/templates/simple-report.tex`: article class, 1in margins, economics math packages, tables (`booktabs`, `threeparttable`, `array`, `longtable`), figures (`graphicx`, `float`, `caption`, `subcaption`), lists (`enumitem`), `siunitx`, `natbib`, `hyperref`, `cleveref`, theorem and lemma environments, placeholder sections.
- `SKILL.md` Defaults: one line saying a new homework, report or short piece as a file starts from the template and keeps its design.
- `multirow` was left out because it is not in a minimal TinyTeX install and would stop compilation.

- `econ-learn/templates/simple-notes.tex` was rewritten in the same style at the user's request: same preamble as `simple-report.tex`, "Lecture Notes" title, the original three sections. `tests/test_professor_contracts.py` pins the new `amsmath` line. `simple-notes-cn.tex` is unchanged.

## Files affected

- `skills/econ-learn/templates/simple-notes.tex`, `tests/test_professor_contracts.py` — notes template restyled.

- `skills/econ-write/templates/simple-report.tex` — the template.
- `skills/econ-write/SKILL.md` — pointer to the template.
- `link/` — regenerated by `tools/build_all.py`.
- `CHANGELOG.md` — entry.

## Behavior and compatibility

`econ-write` now has a template to start from when asked for a new document as a file. Editing existing text and files is unchanged.
